# 💎 Luxury Beauty Salon UI

A premium, modern beauty salon website UI built with **Next.js, ShadCN UI, Tailwind CSS, and Framer Motion**.  
Designed with a focus on **luxury aesthetics, smooth animations, and clean user experience**.

---

## ✨ Features

- Elegant **hero section with smooth animations**
- Interactive **services category filtering**
- Premium **glassmorphism contact form**
- Auto-animated **carousel strip**
- Responsive **luxury layout (mobile-first)**
- Smooth **hover and scroll animations**
- Structured **modular component architecture**

---

## 🧱 Tech Stack

- **Next.js 16 (App Router)**
- **TypeScript**
- **Tailwind CSS**
- **ShadCN UI**
- **Framer Motion**
